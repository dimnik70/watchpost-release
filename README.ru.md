# Watchpost

[English](README.md)

Watchpost объединяет камеры, видеорегистраторы и остальную инфраструктуру объектов в одном приложении. Не имеет значение один ли у вас объект или десятки объектов клиентов - вся нужная информация и инструменты работы с оборудованием всегда доступны.

## Создан для каждой платформы

Watchpost создаётся для macOS, iPhone и iPad, Windows, Android и Linux. Интерфейс каждого приложения нативен для своей платформы и использует её возможности: программа привычно выглядит и работает на том устройстве, которым вы пользуетесь. Версия для Linux запланирована; доступность и функции различаются между платформами.

## Разные производители - одно приложение

Работайте с устройствами разных производителей в одном пространстве. Watchpost поддерживает оборудование Hikvision и Xiongmai, Dahua, ONVIF, OpenIPC и список совместимого оборудования постоянно расширяется с новыми релизами. Доступные функции зависят от устройства, протокола и платформы - актуальные сведения приведены в описании выпуска.

Список поддерживаемых функций при работе с оборудованием любого из поддерживаемых производителей не уступаюет их оригинальным приложением.

## Все объекты на своих местах

Реестр Watchpost - больше, чем список камер. Он объединяет по объектам камеры, регистраторы, роутеры, коммутаторы, радиомосты и ИБП, а также сведения, необходимые для доступа к ним.

- Поиск камер, регистраторов и другого активного оборудования в локальной сети.
- Групповой импорт списка устройств из Excel или CSV.
- Мониторинг доступности устройств.
- Передача сведений об объектах через встроенный механизм Watchpost Inbox или другим удобным способом клиентам или коллегам.

## Удалённый доступ через Watchpost Hub

Watchpost Hub создаётся для связи объектов с приложением без проброса портов устройств и необходимости иметь белый IP-адрес на объекте. Объекты подключаются к Hub со своей стороны, а Watchpost выбирает доступный маршрут: удалённую камеру можно открыть привычным способом, как в локальной сети.

Есть два варианта: собственный Hub на VPS с установкой из приложения или готовый Hub от Watchpost. Через Inbox можно передать пакет объекта коллеге или клиенту, чтобы он принял его в приложении. Возможности Hub и доступность готового сервиса постоянно развиваются;

**Watchpost находится на стадии альфа-тестирования.** Возможности приложения могут меняться, в работе возможны ошибки. Мы будем рады вашим отзывам и предложениям.

Этот репозиторий предназначен для публикации сборок Watchpost и не содержит исходного кода приложения. Подробнее о проекте - на сайте [watchpost.app](https://watchpost.app/).

## Загрузка и установка

Откройте [страницу релизов](https://github.com/dimnik70/watchpost-release/releases) и выберите выпуск для своей платформы. Альфа-версии могут быть отмечены как предварительные (pre-release): откройте описание выпуска, чтобы найти файлы. В нём же приведены доступные сборки, инструкции по установке и дополнительные требования конкретной версии.

| Платформа     | Минимальная версия системы            | Установка                                                                          |
| ------------- | ------------------------------------- | ---------------------------------------------------------------------------------- |
| macOS         | macOS 14                              | Скачайте сборку для macOS и следуйте инструкции в описании выпуска.                |
| Windows       | Windows 10 версии 2004 (сборка 19041) | Скачайте сборку для Windows и следуйте инструкции в описании выпуска.              |
| Android       | Android 8                             | Скачайте сборку для Android и следуйте инструкции по установке в описании выпуска. |
| iPhone и iPad | iOS 17 или iPadOS 17                  | Следуйте инструкции по получению и установке в описании выпуска.                   |
| Linux         | Будет объявлено                       | Версия запланирована; сведения о выпуске появятся по мере готовности.              |

Доступность сборок и возможности могут различаться между платформами. Подробнее - на [странице загрузки](https://watchpost.app/ru/download/) и в [документации](https://docs.watchpost.app/ru/).
